# Changelog

## Unreleased
- Paste the sticker file **alone**: CKEditor's ImageUploadEditing skips pasted
  files when the clipboard also carries `text/html`, so our own "helpful"
  text/html + text/plain entries were what silently killed the Teams upload.
- Picker's own fields can no longer be captured as the insert target — the
  search box autofocuses during React's commit, which fired `focusin` before
  `locked` tore the listeners down, so stickers were landing in our own input.
- Send waits for the sticker to actually appear in the compose area; Teams'
  Send button is always enabled, so "enabled" was never an upload-done signal.
- MIT license, README, package metadata; GIPHY key hardcoded as a shared
  limited-quota default, overridable from the options page.
- Click a sticker to insert **and send** it: click the app's real Send button
  once it enables (upload-complete signal), else fall back to synthetic Enter,
  and report "Inserted — press Enter to send" when neither took. Shift-click
  inserts without sending; plain inputs never auto-send.
- Orphaned content scripts (extension reloaded under an open tab) now remove
  themselves instead of throwing "Extension context invalidated" — all chrome.*
  calls route through `src/ext.js`.
- Offline packs: 941 GIPHY stickers (still PNG + animated GIF each) bundled via
  `scripts/fetch_packs.py`; the picker reads them locally, GIPHY is queried only
  when a search matches nothing bundled and a key is set.
- Grid animates on hover; insertion sends the GIF, clipboard fallback flattens
  to PNG.
- `stickers.json` moved to `public/` and fetched lazily — the content script no
  longer carries 250 kB of data into every frame.
- Chat-app insertion: synthetic `paste` of a PNG `DataTransfer` first, then
  `execCommand`, then clipboard + "press Ctrl+V" hint. Fixes Teams/Slack/
  Discord/WhatsApp Web, whose editors discard DOM-inserted nodes.
- `all_frames: true` — Teams' compose box lives in an iframe.
- Service worker proxies image bytes (content scripts lost cross-origin fetch
  in MV3).
- Real meme packs: GIPHY Stickers provider fetched in the service worker, still
  frames only, 10 category queries + free-text search.
- Options page for the GIPHY API key (`chrome.storage.sync`).
- Bundled emoji set demoted to the no-key/offline fallback, with an in-picker
  "Set key" notice.

## 0.1.0 — 2026-08-19
- Initial MemeStick MV3 extension: Shadow-DOM sticker button on focused/hovered
  text fields, category + search picker (React, Tailwind v4, Vite IIFE bundle).
- Local mock sticker set: 53 transparent PNGs behind a `stickerService`
  abstraction, generated by `scripts/gen_stickers.py`.
- Insertion handles contenteditable (`<img>`) and controlled `input`/`textarea`
  (native value setter + bubbling `input` event).
